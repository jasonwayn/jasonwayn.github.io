I work on systems for machine learning inference — making models efficient enough to run where they are actually used: on phones, edge accelerators, and servers under real concurrency.

Research interests

  • Efficient inference systems. How latency, memory and energy trade off across the serving stack, and where reported speedups stop holding as the deployment context changes.
  • Inference on constrained hardware. Ahead-of-time compiled accelerators, mobile GPUs and DSPs, and the memory and storage hierarchy underneath them.
  • Systems measurement. Building and testing hypotheses through profiling and controlled experiments, especially when apparent hardware limits turn out to come from runtimes, toolchains, or implementation choices.

Research projects

2026 · server-class accelerator

Speculative decoding on a compiled accelerator

Speculative decoding is naturally dynamic; compiled accelerators fix tensor shapes before execution. I ported the decoder to a server-class accelerator, cut round latency from 96.5 ms to 59.5 ms, distributed it across four cards, and traced a long-context accuracy collapse to a numerical defect in the compiled graph. Most of what looked like a hardware limit turned out to belong to the runtime instead.

2026 · Galaxy S25 · mobile GPU, flash storage

Memory-constrained inference on a phone

Under a phone's memory budget, either weights or KV cache may need to leave GPU memory. I built a KV-streaming path and compared it with weight streaming on a Galaxy S25: the faster choice changed with the prompt/generation mix. These static runs did not impose a total-DRAM cap, so they do not yet establish an eviction policy for a specified memory shortage.
